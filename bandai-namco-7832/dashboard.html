어떻게 가져오고, 어떻게 읽나

집환사는 공개 API가 없고 지수가 앱 안에만 있음(비공개 API 우회는 하지 않음). 현재 지수·등락·거래량·평균값은 Mac 앱의 접근성 요소에서 숫자를 직접 읽음. 창 위치나 크기에 의존하는 고정 좌표와 OCR은 사용하지 않음. 과거 시계열은 앱에서 선택 상태가 확인된 3년 차트의 노란 지수선만 읽고, 접근성으로 읽은 축과 현재값을 대조해 끝점 오차 3% 이내일 때만 채택함.

지표 종류가 IP마다 다름 — 대부분은 종합(总行情)이지만, 유니온아레나는 IP 전체 총지수 대신 단품(裸卡) 지수를 제공함(상세 화면에는 거래량·주/월/분기 평균과 3년 차트가 모두 있어 같은 검증 절차로 수집). 종류가 다르면 IP 간 절대 수준 비교는 의미가 없고, 각자의 추세만 봄.
